# Death May Die physical-card review

All catalogue drafts start **unverified**. Source inspection is not physical-card
acceptance. This sheet tracks the owner's collection review; the app stores local
corrections/checkmarks separately. No card has been marked checked here.

## Review procedure

1. Open **Game → Death May Die → Review condition & relic rules**. No seated
   investigator or active match is needed. Start with **Only cards needing review**.
2. Compare the printed name/edition and every rule: setup instructions, ongoing
   effects versus threshold symptoms, timing, target types, distances, quantities,
   symbols, token placement/removal and exceptions. Correct the editable reminder.
3. For relics, review **both faces separately**, including the printed flip
   requirement in starting-face notes and whether effects replace or add to the
   first face. No automatic flip or skill/counter change is applied by the app.
4. Check only the face(s) actually compared, then **Save reference**. Editing text
   or changing a name invalidates that face's check; empty rules cannot be checked.
   Saved references survive recovery/rematches and prefill future selections.
   Existing match notes are independent; **Fill missing rules from reference**
   fills blank fields without replacing notes already entered.
5. Record the physical card's edition, correction or scan filename in the table.
   A local checkmark does not update the shipped catalogue or this sheet. Report
   corrections/scans with the catalogue ID so a reviewed update can be prepared.

## Scans

Start with rows marked **Missing**, then low-legibility references or rule
conflicts. One flat, readable image per face is ideal; include the whole card,
its title and edge symbols. Avoid glare and sleeves where practical. Use the ID
without its colon as a filename, e.g. `relic-ancient-idol-front.jpg` and
`relic-ancient-idol-back.jpg`; conditions need their rules face. A clearly labeled
multi-page PDF is also fine. Keep original scans outside Git until artwork reuse
and distribution are reviewed; text corrections can be incorporated separately.

The initial catalogue is incomplete. Include any card absent from this sheet,
with its exact printed name and expansion. In particular, confirm whether aliases
such as OCD/Obsessive Disorder and Fear of Crowds/Enochlophobia describe the same
printing before treating them as interchangeable.

## Source notes

Original compact reminders are in `InvestigatorCardRules.kt`, with a source per
entry. They are not exact transcriptions. Community wiki text has missing verbs,
corrupted symbols and ambiguous tokens in some entries; those effects are not
invented. Readable Fear of the Unknown/Season 4/bonus photographs supply several
drafts; preview editions and old-printing names still need the owner's check.
