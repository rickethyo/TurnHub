# TurnHub Legal and IP Working Reference

This directory is the development-time record for third-party dependencies, licensing, attribution, trademark references, and IP hygiene decisions.

It exists to make later legal review easier and to prevent provenance/licensing questions from being reconstructed from memory after the product is already built.

## Documents

- [Dependency and IP Tracker](DEPENDENCY_TRACKER.md) - living inventory of third-party software, assets, game/trademark references, status, and release actions.
- [IP Hygiene Rules](IP_HYGIENE.md) - engineering rules for adding libraries, copied/reference material, creative assets, and compatibility references.
- [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) - repository-level human-readable notice index intended to evolve toward the notice package used for releases.

## Maintenance rule

Update these records in the same development cycle that introduces a new third-party dependency, asset, reference implementation, trademark reference, or licensing obligation.

Unknown provenance is not considered cleared provenance. If the source or permission cannot be identified, do not treat the material as approved for production use.

## Scope

These documents are engineering records and risk-management aids. They do not replace professional legal advice, formal trademark/patent searches, or a release-time license-compliance review.
