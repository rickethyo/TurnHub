Design system

One set of tokens for the Atlas portal and the Android app. Pick a theme to see every specimen and the Game screen change together.

Direction

Calm by default, loud only for the turn

The active turn, its clock and life totals are the only things that glow. Everything else sits back on quiet surfaces and hairlines, so a glance across the table lands on whose turn it is.

Color

Semantic tokens

Components never name a color, only a role. Each theme fills the roles and the build checks their contrast against WCAG 2.2 before it writes a file.

Type

Inter, with tabular figures for every number that changes

Clocks and life totals use tabular figures so digits never jitter as they count. Brass swaps the display face for Cinzel, the face already on the Atlas screen and the Sigils.

Icons

An original line set, one stroke weight

Drawn on a 24-point grid at 1.75 stroke with round ends. The same source becomes an SVG sprite for the portal and vector drawables for Android.

Player icons

Filled glyphs, two tones, on the player's color

The presets from shared/include/avatars.h, drawn on the same 24-point grid as solid shapes with a lighter second tone. Atlas's screen and the Sigils draw the 16x16 one-bit versions of the same icons.

Motion

Springs, not timelines

Three springs cover every movement. The portal plays them through CSS linear() curves generated from the same physics Android uses, and Reduce motion turns them all off.
