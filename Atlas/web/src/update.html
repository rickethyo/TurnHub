Update Atlas

Install a signed .thfw package: Atlas firmware, or the portal pack (portal-x.y.z.thfw). A portal pack goes onto the microSD card and needs no restart.

  1. 1
    Between games

    Start updates from Lobby or Game Over.

  2. 2
    Verify at the table

    In Device Settings, tap Verify at the table and type the code the Atlas screen shows. Then upload within 10 minutes.

  3. 3
    Upload the package

    Atlas checks the signature first. Firmware restarts Atlas by itself once it is written.
